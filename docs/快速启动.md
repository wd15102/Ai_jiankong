# 快速启动（全新机器 / 换电脑部署）

> 本文档基于当前**最终方案**：微信回调走**花生壳内网穿透**（固定域名）。
> 如果你是从旧版本迁移过来的，注意 Cloudflare Tunnel 已弃用，见 [穿透方案.md](./穿透方案.md)。

---

## 0. 前置条件

| 依赖 | 说明 |
|------|------|
| Node.js >= 18 | 零框架依赖，只用内置模块（唯一第三方依赖 `jimp`，用于图片处理） |
| 萤石开放平台账号 | 拿 AppKey / AppSecret，并把摄像头加进账号 |
| 微信公众平台**测试号** | https://mp.weixin.qq.com/debug/cgi-bin/sandboxinfo 扫码即得，无需认证公众号 |
| 花生壳客户端 | 提供固定外网域名，把微信回调转发到本机 8787 |

---

## 1. 安装依赖

```bash
npm install
```

---

## 2. 写配置文件

```bash
copy config.example.json config.json
```

然后编辑 `config.json`（**此文件已被 .gitignore 排除，不会上传 Git**）：

| 字段 | 去哪拿 |
|------|--------|
| `appKey` / `appSecret` | 萤石开放平台 → 我的应用 |
| `devices[].serial` | 摄像头机身标签 / 萤石 App 设备详情 |
| `ai.providers[].apiKey` | 各家视觉大模型平台（agnes / 智谱等，OpenAI 兼容接口） |
| `wxTest.appId` / `appSecret` / `templateId` | 微信测试号页面 / 新增模板消息后生成的模板 ID |
| `wxServer.appId` / `appSecret` / `token` | 公众号（测试号）后台，`token` 自己起一个，要和后台填的一致 |
| `wxTest.publicBase` | 花生壳给你的外网域名，例如 `http://xxxxx.vicp.fun`（**不要带路径**） |

设备不想监控就设 `watch:false`；彻底不想看到（含看板和推送）再加 `hidden:true`。

---

## 3. 配置内网穿透（花生壳）

1. 安装并登录花生壳客户端，开机自启
2. 添加映射：**HTTP** → 外网端口 80 → 内网 `127.0.0.1:8787`
3. 拿到固定域名，例如 `http://xxxxx.vicp.fun`
4. 把域名填进 `config.json` 的 `wxTest.publicBase`

验证（在本机命令行，注意加 `--noproxy` 绕开代理）：

```bash
curl --noproxy '*' http://你的域名.vicp.fun/health
# 期望返回: {"ok":true,"app":"webhook",...}
```

## 4. 配置微信测试号

进入 https://mp.weixin.qq.com/debug/cgi-bin/sandboxinfo ：

- **接口配置信息** → URL 填花生壳域名，**Token** 填 `config.json` 里 `wxServer.token` 的值，消息加解密选**明文模式** → 提交（微信会自动做签名校验）
- **模板消息** → 新增一个模板，把生成的模板 ID 填进 `wxTest.templateId`
- **自定义菜单** → 按需加点击事件，常用 key：`today`（今日有人）、`kanjia`（当前画面）、`shot_bk`（双溪村抓拍）、`shot_bg`（木山村抓拍）、`status`（设备状态）

用手机扫码关注测试号，关注者 openid 会出现在测试号页面，把它填进 `config.json` 的 `openidNames`（用于推送时加称呼）和 `wxGroups`（用于分组权限）。

## 5. 启动

双击 **`一键启动全部.bat`**。它会依次：拉起穿透 → 停掉旧进程 → 启动三个服务 → 健康检查 → 自动打开看板 → 进入守护循环（服务挂了自动重启）。

按 `Q` 优雅停止并释放端口；直接关窗口则服务留在后台继续跑。

| 服务 | 端口 | 文件 | 作用 |
|------|------|------|------|
| Web 看板 | 8790 | `webapp.js` + `webapp.html` | 本地/局域网可视化控制台 |
| 微信服务 | 8787 | `webhook.js` | 公众号回调、抓图、推送、AI 跟进、每日日报 |
| 常驻监控 | — | `monitor.js watch` | 轮询报警列表，触发抓图 + AI |

## 6. 日常命令

```bash
node monitor.js status              # 看 token / 设备在线 / AI 渠道顺序
node monitor.js capture [序列号]     # 只抓一张图
node monitor.js once [序列号]        # 全链路自测（绕过"有人"门控，必定推送）
node monitor.js watch [秒]           # 常驻监控
node monitor.js ptz up|down|left|right [序列号]   # 云台转动 0.8 秒
```

根目录还有这些快捷 bat，双击即可：

| bat | 作用 |
|-----|------|
| `一键启动全部.bat` | 启动全部服务（推荐日常用这个） |
| `停止服务.bat` | 停止所有服务并释放端口 |
| `报警看板.bat` | 只开 Web 看板 |
| `公众号看家服务.bat` | 只开微信服务（前台，方便看日志） |
| `常驻监控.bat` | 只开轮询监控 |
| `状态检测.bat` | 打印系统状态 |
| `手动抓图分析.bat` | 手动跑一次全链路 |
| `发送引导消息.bat` | 给所有关注者发一条使用说明 |
| `tailscale_status.bat` | Tailscale / Funnel 健康自查 |

## 7. 常见问题

**微信里点菜单提示「服务出现故障」**
→ 99% 是穿透链路断了。先 `curl --noproxy '*' 你的域名/health`，不通就检查花生壳客户端是否在运行、映射是否还在。

**`curl` 测花生壳返回 503，但手机能用**
→ 你开了 Clash 等代理，出口 IP 被花生壳判定为数据中心而限流。加 `--noproxy '*'` 再测，那是代理的干扰不是真实状态。

**抓图失败 / 提示配额**
→ 萤石免费版：抓图 100 次/天/设备，全部 HTTP 接口合计 1000 次/天/账号。别把 `watchIntervalSec` 调到 120 秒以下。

**AI 一直失败**
→ 用 `node monitor.js status` 看 AI 渠道顺序，失败渠道会进入 5 分钟冷却并沉底；检查 `apiKey` 和 `baseURL`。

**摄像头抓图异常**
→ 确认萤石 App 里「视频内容加密」是关闭状态。
