## BAT 文件编码规则（血泪教训）

### 必须遵守
1. GBK 编码 - Windows cmd 默认使用 GBK，UTF-8 中文会乱码
2. CRLF 换行 - 纯 LF 会让 cmd 括号块解析错位
3. 不能加 chcp 65001 - 会破坏中文显示

### 正确流程
写 UTF-8 临时文件 
→ PowerShell 单条命令读 UTF8 + 替换换行 + 写 GBK
→ 完成

### PowerShell 转换代码
$utf8Content = Get-Content 'input.txt' -Raw -Encoding UTF8
$crlfContent = $utf8Content.Replace([char]10, [char]13+[char]10)
$gbkBytes = [System.Text.Encoding]::GetEncoding('GBK').GetBytes($crlfContent)
[System.IO.File]::WriteAllBytes('output.bat', $gbkBytes)

### 关键教训
必须一次完成 GBK+CRLF 转换
先转 GBK 再单独转 CRLF 会破坏中文变???
